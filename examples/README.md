# Examples

This folder contains compact, public-facing examples for the GeoDisaster benchmark and agent
runtime. The main README uses these examples to illustrate how a task combines question text,
declared evidence handles, tool-grounded intermediate artifacts, and a structured final answer.

Representative examples shown in the project page cover:

- **Flood-safe routing:** route planning and comparison under flood-aware constraints.
- **Multi-hazard exposure estimation:** hazard evidence, exposure layers, and numeric synthesis.
- **Building-damage assessment:** pre/post imagery, building polygons, severe-damage ranking, and
  structured regional summaries.

The complete executable examples live in the Hugging Face dataset as full single-agent and
multi-agent trajectories, with matching task ids across the core, single-agent, and multi-agent
forms.
